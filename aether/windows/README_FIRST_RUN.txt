AETHER — START HERE

FIRST TIME ONLY:
1. Extract the complete ZIP to a normal folder, e.g. C:\AETHER.
2. Double-click SETUP_AND_RUN.bat.
3. Accept any Windows/winget installer prompts.
4. Wait for Python, Node.js, Ollama, project packages and the local Qwen model to install/download.
5. When setup finishes, AETHER starts automatically.

EVERY TIME AFTER:
Double-click START_AETHER.bat.

IMPORTANT:
- Initial setup requires internet.
- The local model download is several GB and may take time.
- Ollama model inference is local after download; no OpenAI/Gemini/Claude API key is needed.
- Keep the two terminal windows open while using AETHER.
- Close those terminal windows to stop the backend and desktop dev server.
- This setup script installs prerequisites automatically; it cannot make a Windows PC run Python/Node/Ollama without installing those runtimes.
- The app is still a development build. It is not yet a signed single-file installer.
